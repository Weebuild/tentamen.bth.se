iCloud: not connected

iCloud needs an app-specific password (your normal Apple ID password won't work). Make one at account.apple.com › Sign-In and Security › App-Specific Passwords. It is saved only in this browser and is only sent to Apple's iCloud servers.

Google opens one tab per event so you can press Save in each. iCloud adds the exams straight into the calendar you pick, and they sync to your iPhone. Adding the same exam again updates it instead of making a copy. The .ics file works with any calendar app (and Google's Import).
